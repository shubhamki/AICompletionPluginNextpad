# Writing Assistant 0.1.0 — preview

Native Nextpad++ macOS plugin for automatic code completion, code improvement and
fixes, prose continuation, rewriting and grammar correction through local model
servers. Suggestions require explicit acceptance and support one-step Undo.

First run: install/open Ollama and run `ollama pull qwen2.5-coder:0.5b`, or start
LM Studio with a coding/chat model. In Local model settings, choose the server
preset, Load models, select a model, Test connection, and Save. Automatic
suggestions require opt-in. Custom nextpad profiles are optional.

Download `WritingAssistant.zip` and import it through Nextpad++'s plugin import
flow, then restart after preserving any unsaved documents. It contains the matching
`WritingAssistant/WritingAssistant.dylib`, setup documentation, version and license
notices. Models and servers are installed separately. Corresponding GPL source is
provided in `WritingAssistant-0.1.0-source.tar.gz` and the exact `v0.1.0` tag.
Verify the downloaded assets against `SHA256SUMS`.

Validation: universal arm64/x86_64 compilation targeting macOS 12, 107 core checks,
seven-command ABI load/shutdown, synthetic HTTP/model-list tests, public Qwen
chat/FIM examples, static analysis, source privacy scanning and package checks.
Prior editor tests on Nextpad++ 1.1.2 verified acceptance, Undo and setup error
handling. The latest model dropdowns have not completed live UI verification.

Limitations: preview release; Intel execution, full IME/split-view coverage and a
live LM Studio server remain unverified. The dylib is ad-hoc signed, not Developer
ID signed or notarized. Downloaded/quarantined installation behavior still needs
validation. Completion is limited to bounded current-document context and one
code line. Model output is not executed or semantically verified. A loopback server
may be cloud-backed; choose and configure a local model. Inference failures pause
automatic suggestions until a successful connection retest.

The catalog submission is a draft pending remaining verification and maintainer
review. This release is independent and is not an endorsement by Nextpad++.
